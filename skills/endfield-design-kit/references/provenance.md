# 来源与许可

本技能以《明日方舟：终末地》的工业视觉语言为灵感，并提炼了经授权界面原型中的 Yellow Paper 变体：浅纸色、灰色面板、亮黄/柔黄、墨黑文字、短切角、展开的英文标签和中文粗标题。通用组件继续使用 `.yp-*` 前缀，避免因产品命名改动而破坏已有样式。

视觉参考包括 [hhikr/endfield-ui-skill](https://github.com/hhikr/endfield-ui-skill) 与经授权的界面原型。本包组织独立的网页与可编辑演示工作流，不需要先安装该上游技能。完整归属见随包 NOTICE.md；不包含游戏官方素材。

设计说明、示例代码和模板按随包 `../LICENSE` 的 MIT 条款提供。保留 MarsWorkbench contributors 的版权与许可；如转发修改后的套件，继续保留许可。这个许可不改变用户后来放入的内容或第三方素材的版权。

Saira 原字体来自 The Saira Project Authors / Omnibus-Type：

- 上游：https://github.com/Omnibus-Type/Saira
- `../assets/web/fonts/Saira.ttf` 为随项目保留的原字体。
- `../assets/web/fonts/saira-ui.woff2` 为项目已有的拉丁/符号 UI 子集。
- 字体按 SIL Open Font License 1.1 单独许可，全文在同目录 `Saira-OFL.txt`。字体不归 MIT 许可，不单独售卖字体。

模板不包含微软字体文件；微软雅黑/Arial 仅是字体名。目标系统没有这些字体时，可以选用已获得授权且包含所需字符的字体，随后检查重排效果。
