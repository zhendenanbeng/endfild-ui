# 网页与应用界面

## 落地起点

`../assets/web/` 是离线可运行的 HTML/CSS/JS 示例。双击 `index.html` 可预览。复制到工程时一起带上 CSS、JS 和 `fonts/`，字体和许可保留相对路径。

`theme.css` 定义 `.yp-*` 组件，`tokens.css` 定义语义变量，`demo.js` 仅驱动演示页。已有 React/Vue/Svelte 项目可把 CSS 变量和组件类移入当前样式系统，按原有状态管理实现交互，无需引入示例 JS。

`tokens.css` 从 `../assets/tokens.json` 导出。改色时修改 JSON 并重新导出，避免网页与其他载体各自猜色。输出项目可按需要保留自己的变量命名和构建流程。

## 三种结构

**工作台**：86px 左侧导航，标题与主要入口在上，观测/筛选或项目选择紧接内容，主数据区旁放当前选项和任务状态。数据表可横向滚动，工具行可换行。

**展示页**：大标题、简短说明和一个主要视觉内容，少量真实指标或章节编号。不要把管理后台的整排工具按钮放进首页。

**阅读页**：单列正文或文图并列，连续标题层级、来源和表格。可用 `.yp-document` 和打印样式，不需要工作台侧栏。

## 组件角色

- `.yp-button--signal`：一处最主要动作，黄底黑字。
- `.yp-button--solid`：黑底/深色动作，适合导出、打开等次级操作。
- `.yp-button`：灰底普通操作；非激活标签优先用文字和细线。
- `.yp-panel`：完整矩形的内容分区；标题上方短线作为定位标记。
- `.yp-table-wrap`：限制表格溢出范围；深色表头、细分隔线、黄色选中标志。
- `.yp-status`：状态文字配圆点；需要区分错误/成功时使用各自语义类。

切角外的焦点提示需要额外留白或在组件内显示，避免被 `clip-path` 裁掉。触控区域至少 44px；不要靠颜色或 hover 才能找到重要操作。

## 响应式与实际功能

在约 900px 时把操作区移到主视区下方；手机收窄导航并允许工具换行。整个文档不应产生水平滚动，宽表格由自己的容器滚动。报告或文章可以直接隐藏导航。

保持项目原来的输入校验、加载、空状态、失败与取消逻辑。样式类不能让禁用按钮看起来可用，也不能把组件例子的静态成功状态接到实际任务上。

## 验证

实际检查深色/浅色、亮黄/柔黄、键盘焦点、窄屏和长文案。查看字体是否成功加载，按钮和表格是否可操作。`demo.js` 的示例记录和曲线有明确 DEMO 标记，替换为业务代码后去掉演示数据与提示。
