# PPT 与演示文稿

## 使用模板

`../assets/slides/yellow-paper-template.pptx` 提供六页可编辑起点：封面、章节页、图文页、数据图表页、比较表页、后续工作页。可复制、删减或组合；页数由当前任务决定。

模板中“项目汇报”等文字和示例数值用于展示版式。生成成品时替换为用户内容，移除不适用的占位说明；示例数据不能变成项目结论。需要延续已有 PPT 时，以用户提供的文件为内容与版式依据，按授权范围套用颜色和视觉元素。

用目标环境能编辑 PPTX 的工具生成，或直接改随包模板。这个技能不依赖某个作者本地路径、特定 MCP 或私有 Node 包。若环境提供演示文稿技能，可配合其导出和渲染流程。

## 从网页迁移的比例关系

| 网页特征 | PPT 的对应做法 |
|---|---|
| 亮黄当前项边缘 | 标题旁短黄线、页内一个重点或章节色块 |
| 窄侧栏与工具条 | 通常移除；用清楚的章节和页序替代 |
| 小英文标签 + 中文粗标题 | 保留层级，但把标签放大到可投影阅读的大小 |
| 灰色面板 | 必要时用于证据底板，避免每页变成多卡片仪表盘 |
| 按钮切角 | 只有需要表现操作原型时保留；正文页不用假按钮 |
| 连续表格 | 分页或提取当前问题所需行列，表头仍保留单位与定义 |
| 深浅色切换 | 选择一套主色；深色可用于少量章节页，避免逐页随机变色 |

## 可编辑性

文字、表格、图表、流程与必要的几何布局保持原生对象。数据图使用原生图表并保留工作簿或数据来源；不要把表格或整页文字烘焙成 PNG。真实照片、扫描件和用户提供的证据图保持图像原件，按比例放置。

画布默认 16:9。以 1280×720px 设计时，96px 对应 72pt；若工具用像素，不能把 `32` 误当作 32pt。模板主标题约 36pt，正文约 21pt，必要注释约 14pt；内容塞不下先改写或分页。

中文默认微软雅黑，英文/图表默认 Arial。二者是对换机可读性的折中。需要更贴近网页的宽体英文时，使用随包 Saira 字体并检查目标电脑；字体未嵌入时不要宣称跨机器字形完全一致。另一个系统可以整体换为可用的思源黑体等，但要重新渲染查看。

## 交付检查

逐页渲染，检查边界、文字换行、图表刻度、颜色含义和空白比例。确认表格与图表仍可编辑，原始数字、单位、来源及不确定性没有随样式丢失。按实际环境说明验证范围；只做渲染检查时不要声称已在 PowerPoint 或 Google Slides 实机验证。
