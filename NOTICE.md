# Attribution and scope

Endfield Design Kit is an unofficial design toolkit inspired by the industrial visual language of **Arknights: Endfield / 明日方舟：终末地**. It is not affiliated with or endorsed by the game's owners. Game names remain the property of their respective owners.

The toolkit contains original instructions, reusable layouts, generic UI code and example data. It ships no official game screenshots, logos, characters, audio or proprietary game fonts.

The visual direction was informed by [hhikr/endfield-ui-skill](https://github.com/hhikr/endfield-ui-skill) and an authorized local UI prototype. This project organizes its own web and editable presentation workflow. It does not redistribute that upstream repository as a mirror. The MIT copyright notice retained from the prototype remains in `LICENSE`.

The bundled **Saira** font is Copyright 2020 The Saira Project Authors, distributed under **SIL Open Font License 1.1**. The original TTF and the prototype's Latin/symbol WOFF2 subset retain their separate font license at `skills/endfield-design-kit/assets/web/fonts/Saira-OFL.txt`. The MIT license does not relicense these font files.

The PPTX template names Microsoft YaHei and Arial as system fonts but does not include their font files. All sample values are synthetic and describe layout demonstrations, not real experiments or model performance.
