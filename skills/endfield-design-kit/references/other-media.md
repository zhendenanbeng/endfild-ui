# 阅读报告、文档与海报

沿用纸色、墨黑、细线和少量黄色，重新安排信息密度。

**HTML 报告**：使用 `.yp-document` 单列阅读区，表格和图像自适应。正文约 15–17px，链接使用黑色下划线而非黄色细字。打印时隐藏导航、按钮和交互提示，保留标题、单位、来源和图例。

**Word / PDF**：按纸张尺寸定正文和边距。中文段落保持常规黑体，粗体只给标题与重点；章节短黄线可以替代彩色大底。页眉、页码和真实版本信息可少量保留。选择适合文档的本机工具，导出后查看真实分页，不用网页 px 尺寸直接套印刷字号。

**海报 / 信息图**：先确定观看距离、画幅和最重要的一条信息。放大中文标题，英文只作简短辅助；以大幅真实图像、清楚的数据图或少量必要文字形成主体，不把所有内容挤进表格和卡片。

不同载体共用 `../assets/tokens.json` 的颜色角色。替换项目名称、品牌和内容，不默认复用 MarsWorkbench 的仪器名字或标志。用户要求保留原有颜色编码和正式模板时，优先满足该约束。
